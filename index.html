Como deixar compartilhado

  1. Crie uma conta grátis em supabase.com e um projeto novo.
  2. No menu SQL Editor, cole e rode o comando abaixo.
  3. Em Project Settings → API, copie a Project URL e a chave anon public.
  4. Cole as duas aqui ao lado e clique em Conectar.
  5. Mande o link do app para a equipe. Todos passam a ver os mesmos lançamentos.
